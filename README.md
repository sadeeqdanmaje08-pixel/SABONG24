# 🐓 SABONG24 Telegram Bot

Your all-in-one Telegram bot for sabong schedules, live events, results, and streams.

## Features
- 📅 Daily fight schedules
- 🏆 Live event updates
- 📊 Real-time results
- 🎥 Streaming links
- 💬 Community access
- 🕐 Active hours (8 AM – 11 PM PHT)

## Deploy on Railway

1. Push this repo to GitHub
2. Go to railway.app → New Project → Deploy from GitHub
3. Add variables:
   - BOT_TOKEN
   - ADMIN_ID
4. Deploy 🚀
